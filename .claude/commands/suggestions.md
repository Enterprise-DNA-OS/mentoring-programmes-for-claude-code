# Review skill-based match suggestions

Run `npm run mentoring -- suggestions --json`.

Read the returned records before answering. Present the relevant names, dates and next actions. Missing evidence stays missing. Resolve ambiguous names with the operator.

Suggestions use declared skills and available capacity only. They are not an employment suitability score. Read both profiles and obtain the actual agreement before recording a pair. Never infer preferences from protected or sensitive characteristics.
