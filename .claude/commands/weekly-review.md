# Prepare the Monday programme review

Run `npm run mentoring -- weekly-review --json`.

Read the returned records before answering. Present the relevant names, dates and next actions. Missing evidence stays missing. Resolve ambiguous names with the operator.

Run quiet-pairs, unmatched and goal-progress separately to ground the review. Then run weekly-review for capacity and record checks. Lead with overdue pairs and goals, identify the owner of each action, and list unconfirmed participation separately from available matches. Draft only.
