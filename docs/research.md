# Selection evidence

Checked 2 November 2026. New family: mentoring-programmes. Existing workforce-training tracks course obligations, and performance-reviews tracks appraisal cycles. This build handles voluntary mentor relationships, capacity and session follow-through. It does not cover recruitment.

Together scored 21/30: annual bill 2, data-shaped 5, buyer fit 2, search demand 3, one-session buildable 5, import path 4. SuccessionHR scored 17/30 (2,5,2,2,5,1): five-figure upper tiers, but no documented record export found. MentorcliQ scored 18/30 (1,5,2,3,5,2): published starting price below the bill threshold and unspecified export columns.

[Software Advice](https://www.softwareadvice.com/product/182248-Together/) reports a US$10,000 annual starting price. This is third-party pricing, not a verified customer invoice or current Together offer. [Together's current pricing page](https://www.togetherplatform.com/pricing) uses custom quotes based on learners, match types and programme goals, charges for actively matched users, and includes implementation and support. The landing page therefore uses no dollar figure. The older /get-pricing page carries different information and is not used as the current offer.

No verified Together buyer was found in the local customer and CRM material searched. No live CRM read is claimed. Search results contain current comparison pages; search volume was not measured. Buyer fit is an inference for organisations running mentoring cohorts, not evidence that our existing customers pay for this product.
